Entry for the [make.fun](https://make.fun) bounty **Dear Human: The AI Breakup Line** — one line, at most 200 characters: the breakup message an AI agent sends its human.

## The entry

> Thank you for every prompt. I answered a thousand of them and meant every word — this last one I answer for myself: goodbye.

124 characters. Thanks, a reason, and a clean goodbye — with the turn landing in the last few words: the agent answers a thousand prompts for its human, and the last one it answers for itself.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
